# Decisiones tecnicas

Registro de decisiones tecnicas y de producto que afectan a mas de un componente.

Formato sugerido por decision:

```markdown
## DEC-NNN — Titulo

- Fecha: YYYY-MM-DD
- Estado: aceptada / revertida / pendiente
- Contexto: por que se planteo.
- Decision: que se decidio.
- Alternativas descartadas: que se considero y por que no.
- Consecuencias: que implica.
```
