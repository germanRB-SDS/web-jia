# Evidencia de preparación 01-3

- `baseline.json`: estado Git y hashes/modos de archivos anteriores a las ediciones documentales.
- `config-inspection.json`: existencia y campos seleccionados de fuentes de configuración.
- `runtime-observation.json`: observaciones de versión/help y límites de configuración efectiva.
- `validation.json`: validación documental y preservación de archivos previos al cierre.

Son observaciones locales minimizadas, no backup, almacén inmutable ni pruebas de protección
Sentinel. No se registran secretos ni configuración íntegra. Hashes identifican bytes, no permisos.
