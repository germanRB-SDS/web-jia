# Mobile Sample Code

Runnable, owner-requested reference implementations for native mobile applications. These leaves
are lazy-loaded examples, not production dependencies and not authorization to publish a feature.

Before copying a payment or external-link example into an app, re-check the current distribution
contract, storefront policy, privacy disclosures and review notes. A sample kept outside an app
target must never be wired through a reviewer-only or otherwise hidden feature flag.
