# UI Components

Portable component references with small HTML, CSS, and JavaScript examples.

Load only the component folder needed for the current task. These examples are intentionally plain
HTML/CSS/JS unless a pattern depends on a library, such as SortableJS.

## Available Components

- `frosted-alert-modal/` — one-action frosted alert popup.
- `frosted-confirm-modal/` — two-action frosted confirmation popup.
- `frosted-arrow-buttons/` — previous/next frosted navigation buttons.
- `button-leather-shimmer/` — material CTA button with a leather gradient, relief and a slow glint.
- `carousel/` — responsive carousel with count-based controls.
- `drag-relocate-button/` — handle-only card relocation with SortableJS.
- `expandable-search-filter-panel/` — collapsible bordered panel with an expanding search field and
  progressively disclosed, state-preserving filters.
- `notification-toast-stack/` — accessible animated info/success/error notifications; discovery
  tag `notificaciones-01`.
- `procedural-horizon-hero/` — complete static landscape hero with a quiet copy corridor and an
  optional deferred Three.js enhancement.
