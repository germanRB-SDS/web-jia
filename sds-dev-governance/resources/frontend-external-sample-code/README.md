# Frontend External Sample Code

This legacy-named category indexes frontend examples useful for study. Most leaves are external
reference notes and are not SDS-owned source code. An owner-requested leaf may instead contain
SDS-owned clean-room runnable code when its provenance and license boundary say so explicitly.

Rules:

- Prefer reference notes and clean-room extraction over vendoring source.
- Verify license and asset ownership before copying any external code.
- Never copy third-party brand assets, fonts, logos, screenshots or trademarks into an SDS project.
- When a sample is used for a concrete project, record upstream URL, branch/commit or tree SHA,
  extracted pattern, local adaptation decisions and verification evidence.
- For SDS-owned clean-room samples, record the owned observation source, excluded identity/assets,
  third-party runtime dependencies and empirical reconstruction evidence.

Use these resources only on demand for frontend pattern analysis, design inspiration or implementation
planning.
